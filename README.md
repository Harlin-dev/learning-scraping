# LearningScraping

This repository contains Python web scraping scripts that demonstrate **web scraping, pagination handling, keyword filtering, and data export**. These projects are built for learning and portfolio purposes.

---

## Scripts Overview

### 1. `quotes_keyword_filter.py`
- Scrapes quotes from [quotes.toscrape.com](http://quotes.toscrape.com)
- Filters quotes using a **keyword** (case-insensitive)
- Extracts authors and tags
- Exports results to Excel
- Useful for tasks like brand mention monitoring or topic-specific data collection

### 2. `quotes_pagination.py`
- Handles **pagination** to collect quotes from multiple pages automatically
- Extracts quotes, authors, and tags
- Exports structured data to Excel
- Demonstrates looping through pages and polite scraping practices
